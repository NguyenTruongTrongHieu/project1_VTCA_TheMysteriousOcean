# TheMysteriousOcean - Unity
#Overview

The Mysterious Ocean is a 2D shoot ’em up game where players control a submarine to explore the deep sea. 
During your journey, you will encounter and battle various sea monsters that attempt to attack your vessel..

# Key Features

- Dynamic 2D graphics & immersive sound effects

- Offline high-score system, allowing friends to compete on the same device

- Variety of enemies and challenging bosses

- Difficulty increases progressively across levels

# How to play

- Use WASD or arrow keys to move the submarine

- Press Space to fire

Technology Stack

- Unity

- C#
